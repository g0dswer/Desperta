# Desperta identity fonts

These fonts are bundled locally so identity changes never need a network request:

- `Audiowide-Regular.ttf` — Retrofuturista display face.
- `Orbitron-Variable.ttf` — licensed source of the custom clock face.
- `DespertaDisplay-Regular.ttf` — Orbitron at weight 650, renamed derivative with an unslashed rounded zero and circular colon; generated by `scripts/make-clock-font.py` (fontTools).
- `ShareTechMono-Regular.ttf` — Matrix code and status face.
- `VT323-Regular.ttf` — Terminal antigo display face.
- `PixelifySans-Variable.ttf` — Anos 90 pixel typography ([upstream](https://github.com/google/fonts/tree/main/ofl/pixelifysans)), OFL-PixelifySans.txt.

The upstream fonts are from the Google Fonts repository and are distributed under the
SIL Open Font License 1.1. The corresponding license text is kept beside each font
as `OFL-Audiowide.txt`, `OFL-Orbitron.txt`, `OFL-ShareTechMono.txt`, and `OFL-VT323.txt`.

- Russo One (numeric display): https://github.com/google/fonts/tree/main/ofl/russoone — OFL-RussoOne.txt.
